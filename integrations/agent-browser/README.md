Official @agent-browser/eve 0.38.2 integration, rebuilt from its published JavaScript using Eve 0.70.0. Upstream: https://github.com/vercel-labs/agent-browser/tree/main/packages/%40agent-browser/eve (Apache-2.0). The registry distribution uses Eve 0.57 tool contract v44, unsupported by Eve 0.70. This directory preserves the published implementation and regenerates its compatibility manifest with the installed compiler. Rebuild: ../../node_modules/node/bin/node ../../node_modules/eve/bin/eve.js extension build (from this directory).

Local compatibility fixes: browser session names and installation caches use `ctx.session.id`, because Eve 0.70's public sandbox handle has no `id` field. Screenshot results retain the sandbox path; the root agent's `send_image` tool uploads that file to the owner chat when requested.
